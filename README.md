# Schiller Skip

Full-colour Python 3 neon stone-skip arcade for ElbowOS.

Aim from the pier and skip an iridescent stone across a labradorite lake.
Time the crests, chain combos, and snatch drifting lanterns.
A / D (or Left / Right) aim. Space / W / Up throws.

## Play

```
pip install -r requirements.txt
python3 schiller_skip.py --play
```

## Record a 9:16 reel

```
python3 schiller_skip.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
